# Bootstrap-классы — краткая шпаргалка

CSS в таблице немного упрощён: в настоящем Bootstrap также используются `!important`, CSS-переменные и дополнительные служебные правила.

| Bootstrap-класс | Расшифровка названия | Примерный обычный CSS | Краткое описание |
|---|---|---|---|
| `.container-fluid` | `container` — контейнер; `fluid` — растягивающийся | `width: 100%;` | Контейнер, занимающий всю доступную ширину. |
| `.clearfix` | `clear` — очистить; `fix` — исправление | `::after { content: ""; display: block; clear: both; }` | Позволяет родителю учитывать высоту вложенных `float`-элементов. |
| `.float-start` | `float` — обтекание; `start` — начало строки | `float: left;` | Прижимает элемент к началу строки. В LTR — влево. |
| `.float-end` | `float` — обтекание; `end` — конец строки | `float: right;` | Прижимает элемент к концу строки. В LTR — вправо. |
| `.w-25` | `w` = `width`; `25` = 25% | `width: 25%;` | Задаёт ширину 25% от родителя. |
| `.w-50` | `w` = `width`; `50` = 50% | `width: 50%;` | Задаёт ширину 50% от родителя. |
| `.w-100` | `w` = `width`; `100` = 100% | `width: 100%;` | Растягивает элемент на всю ширину родителя. |
| `.img-fluid` | `img` — изображение; `fluid` — адаптивное | `max-width: 100%; height: auto;` | Не позволяет изображению выйти за границы родителя и сохраняет пропорции. |
| `.d-block` | `d` = `display`; `block` — блочный | `display: block;` | Делает элемент блочным. |
| `.row` | `row` — строка | `display: flex; flex-wrap: wrap;` | Создаёт строку Bootstrap Grid для размещения колонок. |
| `.col-4` | `col` = `column`; `4` = 4 из 12 колонок | `width: 33.333333%;` | Занимает треть строки; три `.col-4` образуют полную строку. |
| `.g-0` | `g` = `gutter`; `0` — без промежутка | `--bs-gutter-x: 0; --bs-gutter-y: 0;` | Убирает промежутки между колонками и строками сетки. |
| `.px-0` | `p` = `padding`; `x` — горизонтальная ось; `0` — ноль | `padding-left: 0; padding-right: 0;` | Убирает внутренние отступы слева и справа. |
| `.p-0` | `p` = `padding`; `0` — ноль | `padding: 0;` | Убирает все внутренние отступы. |
| `.py-2` | `p` = `padding`; `y` — вертикальная ось; `2` — размер | `padding-top: .5rem; padding-bottom: .5rem;` | Добавляет небольшие внутренние отступы сверху и снизу. |
| `.me-3` | `m` = `margin`; `e` = `end`; `3` — размер | `margin-right: 1rem;` | Добавляет внешний отступ со стороны конца строки. В LTR — справа. |
| `.ms-3` | `m` = `margin`; `s` = `start`; `3` — размер | `margin-left: 1rem;` | Добавляет внешний отступ со стороны начала строки. В LTR — слева. |
| `.mb-0` | `m` = `margin`; `b` = `bottom`; `0` — ноль | `margin-bottom: 0;` | Убирает нижний внешний отступ. |

## Сокращения в названиях

| Сокращение | Значение |
|---|---|
| `m` | `margin` — внешний отступ |
| `p` | `padding` — внутренний отступ |
| `t` | `top` — сверху |
| `b` | `bottom` — снизу |
| `s` | `start` — начало строки |
| `e` | `end` — конец строки |
| `x` | горизонтальная ось: слева и справа |
| `y` | вертикальная ось: сверху и снизу |
| `w` | `width` — ширина |
| `d` | `display` — способ отображения |
| `g` | `gutter` — промежуток в сетке |
| `col` | `column` — колонка |
| `img` | `image` — изображение |

Шкала размеров Bootstrap:

```text
0 = 0
1 = 0.25rem
2 = 0.5rem
3 = 1rem
4 = 1.5rem
5 = 3rem
```
